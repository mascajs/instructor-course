# 수업 교안 제작 스킬 시작 안내

## 이 스킬이 하는 일

`lesson-deck-builder`는 수업계획안이나 교안 원고, 디자인 파일, 샘플 PPT를 실제로 읽고 PPTX 또는 HTML 교안을 제작한다.

- 장표 구성이 없으면 사용하는 AI의 일반 추론으로 제작용 장표 초안을 만든다.
- `design.md`와 샘플 PPT를 색·글자·레이아웃·형태·그림자·이미지·모션으로 나누어 적용한다.
- 두 자료가 다르더라도 하나를 통째로 버리지 않고, 사용자가 정한 요소별 조합을 따른다.
- 샘플 PPT를 실제 화면으로 보고 글자 크기, 여백, 정보량, 배치 유형을 참고한다.
- 대표 화면을 먼저 만들고 렌더링하거나 브라우저에서 확인한다.
- 문제가 있으면 해당 부분을 수정하고 최신 파일을 다시 확인한다.

이 스킬은 학습목표가 적절한지 판단하거나 수업계획안을 새로 설계하는 스킬이 아니다. 교육 내용의 분석과 판단은 사용자와 사용하는 AI가 담당한다.

## 사용 전에 확인할 것

- 파일을 읽고 쓸 수 있는 에이전트AI인가
- PPTX를 만들고 화면으로 렌더링할 수 있는가
- HTML을 만들고 브라우저에서 확인할 수 있는가
- 결과물을 저장할 폴더가 준비되어 있는가
- 사용할 제목·본문 글꼴이 설치되어 있거나 글꼴 파일이 준비되어 있는가
- 글꼴을 결과물에 포함하거나 배포해도 되는가

이 기능이 없는 AI에서는 스킬을 설치해도 실제 파일 제작과 화면 검증을 완료할 수 없다.

## 설치

압축을 푼 `lesson-deck-builder` 폴더 전체를 사용하는 에이전트AI의 프로젝트용 스킬 폴더에 넣는다. Codex 프로젝트에서는 일반적으로 프로젝트의 `.agents/skills/` 아래에 둔다. 다른 제품에서는 해당 제품이 안내하는 프로젝트 스킬 위치를 사용한다.

## HTML 교안 시작 예시

```text
$lesson-deck-builder

첨부한 수업계획안, design.md, 샘플 PPT를 실제로 확인해
16:9 HTML 교안을 만들어줘.

수업 내용과 목표를 임의로 평가하거나 삭제하지 말고,
장표 구성이 없으면 네 일반 분석 능력으로 제작용 장표 초안을 먼저 보여줘.
디자인 파일과 샘플 PPT가 다르면 하나를 통째로 고르게 하지 말고
색·글자·레이아웃·형태·그림자·이미지·모션별 적용 출처를 표로 제안한 뒤
결과가 달라지는 항목만 한 번에 물어봐.

제목·본문 폰트의 파일 또는 설치 여부, 배포 가능 여부와 대체 글꼴도 확인해.

내가 확인한 뒤에는 대표 화면 2장을 만들고 브라우저에서 검수해.
문제가 있으면 수정하고 다시 확인한 뒤 내가 요청한 범위까지 이어서 제작해.

제작 범위: [범위]
저장 위치: [폴더]
파일명: [사용자가 정한 한글 이름]
```

샘플 PPT는 [직접 수정할 템플릿 / 레이아웃 참고]로 사용해.

## 사람이 결정할 것

- 결과 형식과 제작 범위
- 디자인 파일과 샘플 PPT에서 요소별로 가져올 규칙
- 제목·본문 폰트와 배포·대체 방식
- 제작용 장표 초안의 채택
- 원고 수정과 삭제
- 최종 결과 사용 여부

AI는 레이아웃 구현, 파일 생성, 화면 검수, 오류 수정을 담당한다.
