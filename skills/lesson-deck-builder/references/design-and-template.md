# 디자인 파일과 샘플 PPT 적용

## 먼저 역할을 분리한다

- 확정 원고는 내용과 순서를 정한다.
- 디자인 파일은 시각 언어를 정한다.
- 샘플 PPT는 화면에서 검증된 크기 관계와 배치 방식을 보여준다.

샘플 PPT가 단순 참고인지, 직접 수정할 템플릿인지 확인한다. 참고라면 원본을 수정하지 않고 레이아웃 원리만 가져온다. 템플릿이라면 복사본에서 작업하고 원본 파일과 마스터·레이아웃 구조를 보존한다.

## 샘플 PPT를 실제 화면으로 분석한다

텍스트만 추출해서 디자인을 판단하지 않는다. 가능한 도구로 전체 장표를 렌더링하고 축소 모음과 대표 장표를 본다.

다음을 장표 번호와 함께 짧게 기록한다.

- 화면 비율과 논리 크기
- 사용 글꼴, 제목·본문·캡션의 크기와 굵기 관계
- 좌우·상하 여백과 정렬 기준선
- 한 화면의 평균 정보량과 줄 수
- 표지, 구간 전환, 설명, 비교, 절차, 활동, 마무리의 배치 유형
- 카드·선·아이콘·이미지·차트가 차지하는 비중
- 반복되는 색, 모서리, 그림자, 강조 방식
- 실제로 재사용할 수 있는 마스터, 레이아웃, 테마, 자산

보지 못한 특징은 추정하지 않는다. 렌더링할 수 없으면 `구조와 텍스트만 확인, 시각 검증 불가`라고 표시한다.

## 디자인 파일을 구현 규칙으로 바꾼다

색상값을 나열하는 데서 끝내지 않고 실제 화면의 적용 위치를 정한다.

| 항목 | 정할 것 |
| --- | --- |
| 배경과 표면 | 기본 배경, 보조 면, 구간 전환 배경 |
| 글자 | 제목, 본문, 캡션, 강조어의 크기·굵기·색 |
| 간격 | 바깥 여백, 문장 내부 줄 간격, 블록 사이 간격 |
| 형태 | 모서리, 선, 그림자, 카드, 버튼처럼 보이는 요소의 용도 |
| 이미지 | 비율, 자르기, 반복 사용, 출처 표시 방식 |
| 모션 | 등장 순서, 비교, 상태 변화 중 어떤 기능을 지원하는지 |

지정 글꼴 파일이 없으면 실제 설치 여부를 확인하고, 없을 때 사용할 대체 글꼴을 사용자에게 알린다. 글꼴 대체 후에는 줄바꿈과 상자 크기를 다시 확인한다.

## 충돌 처리

디자인 파일과 샘플 PPT가 다르다고 해서 전체 자료 중 하나만 선택하게 하지 않는다. 사용자는 샘플 PPT의 뉴모피즘 형태와 공간감은 유지하면서 디자인 파일의 색감과 글꼴을 가져오려 할 수 있다. 먼저 각 자료에서 가져올 요소를 다음처럼 나눈다.

| 요소 | 디자인 파일에서 읽은 것 | 샘플 PPT에서 읽은 것 | 사용자에게 물을 것 |
| --- | --- | --- | --- |
| 전체 분위기 | 밝음·어두움, 감정, 브랜드 인상 | 실제 장표가 주는 인상 | 어느 인상을 유지할지 |
| 색·배경 | 팔레트와 색의 기능 | 배경·표면·강조색 배치 | 어느 색 체계를 적용할지 |
| 글자 | 글꼴·굵기·크기·행간 | 실제 제목·본문 크기 관계 | 사용할 글꼴과 크기 기준 |
| 레이아웃 | 정렬·여백·밀도 원칙 | 검증된 장표 구성 | 어느 배치 원리를 가져올지 |
| 형태·그림자 | 모서리·카드·선 규칙 | 뉴모피즘 등 구체적 스타일 | 스타일을 유지·변형·제외할지 |
| 이미지·아이콘 | 비율·톤·사용 규칙 | 실제 자산과 자리 | 어느 자산·표현 방식을 쓸지 |
| 모션 | 목적·강도·축소 대안 | 전환·단계 공개 방식 | 어느 움직임을 구현할지 |

사용자가 요소별 출처를 정하면 그 조합을 한 문장으로 고정한다. 예: `뉴모피즘의 형태·돌출감·여백은 유지하고 Spotify 디자인 문서의 어두운 팔레트와 기능성 초록을 적용한다.` 서로 다른 디자인을 평균내듯 모호하게 섞지 않는다.

## 폰트 확인

폰트는 제작 전에 다음을 확인한다.

- 사용자가 원하는 제목·본문 글꼴 이름
- 실제 글꼴 파일 제공 또는 제작 환경 설치 여부
- HTML에서 웹폰트로 포함할 수 있는지, PPTX를 다른 PC에서 열 때 대체되는지
- 수업 배포와 홈페이지 공개가 허용되는 라이선스인지
- 글꼴이 없을 때 사용할 대체 글꼴
- 대체 글꼴 적용 뒤 줄바꿈, 글자 폭, 상자 크기를 다시 검수할 방법

전용 글꼴 이름만 디자인 문서에 있고 파일이나 사용 권한이 없으면 사용 가능한 것으로 간주하지 않는다.

## 대표 화면 설계

첫 제작에는 학습 기능이 다른 화면을 고른다.

- 설명·개념형 1장
- 비교·절차·활동형 중 1장

표지만 먼저 만드는 방식은 본문 가독성과 정보량을 검증하지 못하므로 피한다. 사용자가 표지도 요청했다면 본문 대표 화면과 함께 확인한다.
