# PPTX 교안 제작

## 먼저 제작 방식을 확인한다

- 샘플 PPT를 직접 수정하는 템플릿으로 사용할지, 레이아웃 참고로만 사용할지 구분한다.
- 템플릿이면 원본을 보존하고 복사본에서 작업한다.
- 결과가 편집 가능한 PPTX인지, 화면 보존용 이미지 기반 PPTX인지 확인한다.
- 편집 가능한 PPTX 요청을 전체 화면 이미지로 해결하지 않는다.

## 템플릿을 사용할 때

- 화면 비율, 테마, 마스터, 레이아웃, 글꼴, 색, 자리표시자 구조를 확인한다.
- 대표 장표를 렌더링해 실제 보이는 크기와 파일 내부 수치가 일치하는지 본다.
- 기존 레이아웃에 내용을 억지로 넣지 않는다. 원고의 기능과 맞는 레이아웃을 고르고 필요한 경우 최소 범위로 새 레이아웃을 만든다.
- 샘플의 교육 내용과 이미지가 새 교안에 남지 않게 확인한다.

## 편집 가능성

- 제목, 본문, 표, 도형, 차트는 가능한 범위에서 네이티브 요소로 유지한다.
- 표와 차트는 화면 이미지로 대체하지 않는다.
- 이미지와 로고는 비율을 유지하고 원본이 필요한 자산은 원본 파일을 사용한다.
- 그룹화가 편집을 방해하지 않도록 의미 단위로만 묶는다.
- 발표노트가 제공되었다면 해당 장표에 연결한다.
- 사용하지 않는 숨김 장표, 샘플 문구, 제작 메모가 결과에 남지 않게 한다.

## 글자와 배치

- 템플릿이 있으면 그 글자 크기 관계를 우선 참고한다.
- 글자가 넘치면 먼저 문장 배치, 상자 폭, 줄바꿈을 조정한다. 내용을 임의로 삭제하거나 지나치게 작은 글자로 줄이지 않는다.
- 한 문장의 줄 간격과 서로 다른 문단의 간격을 구분한다.
- 제목, 본문, 도형의 시각적 무게를 실제 렌더 화면에서 비교한다.
- 모든 장표를 같은 카드 격자나 좌우 분할에 넣지 않는다. 원고의 기능에 맞는 배치 유형을 사용한다.

## PPTX 검수

- 최신 PPTX를 전체 장표 이미지로 렌더링한다.
- 축소 모음에서 반복, 밀도, 구간 전환, 빈 장표를 확인한다.
- 각 장표에서 잘림, 겹침, 잘못된 줄바꿈, 깨진 글꼴, 이미지 왜곡을 확인한다.
- 제목과 본문이 멀리서 구분되고 핵심 내용이 장식보다 먼저 읽히는지 본다.
- 표, 차트, 도형이 실제로 편집 가능한지 대표 항목을 확인한다.
- 다른 컴퓨터에서 대체될 수 있는 글꼴과 손실되는 효과를 알린다.
- 마지막 수정 후 다시 저장하고 전체 장표를 재렌더링한다.

요청 형식을 실제로 만들거나 렌더링할 기능이 없으면 PPTX 제작을 완료했다고 말하지 않는다. 제작 가능한 환경, 대체 형식, 사용자가 직접 확인할 항목을 구분해 안내한다.
